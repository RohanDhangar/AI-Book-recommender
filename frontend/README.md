# AI Book Recommender — Frontend

React + TypeScript + Vite frontend for the AI Book Recommender project.

## Run locally

```bash
npm install
npm run dev
```

The frontend reads the backend URL from:

```env
VITE_API_BASE_URL=http://localhost:2000
```

For deployment, update the environment variable to the hosted backend URL.

The `.env` file is ignored by Git. Use `.env.example` as the template.
