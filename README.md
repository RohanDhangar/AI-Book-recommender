# 📚 Decode Books

AI-powered book recommendation platform that analyzes user profiles, interests, and resumes to generate personalized book recommendations using Gemini AI and Google Books API.

### Tech Stack

React · TypeScript · Vite · Tailwind CSS · Node.js · Express · MongoDB · Mongoose · JWT · Gemini AI · Google Books API

### Features

- AI-powered personalized book recommendations
- Resume/PDF processing
- JWT authentication with HTTP-only cookies
- Access & refresh token flow
- Google Books API integration
- React + TypeScript frontend
- Node.js + Express backend
- MongoDB database
